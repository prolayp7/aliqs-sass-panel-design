# AI Website Lead Qualifier — admin panel design gallery

Static, no-backend visual explorations of the admin panel (`ailqs-admin`), for client sign-off before the real build. All data is hardcoded mock data — nothing here talks to a real API.

```bash
npm run dev
```

Then open `/` for the gallery, or jump straight to a design:

- **`/design-01`** — “Signal Command”: dark navigation shell with a light operational canvas, urgent signal queue, qualification analytics, lead search/filtering, explainable scoring, conversation and activity views, module-level configuration screens, notifications, responsive navigation, and static interaction feedback.
- **`/design-02`** — “Calm Intelligence”: light nested-enclosure shell (soft gray canvas around a white rounded workspace), a charcoal hero KPI anchor, cobalt primary actions, pill-shaped hot/warm/cold/qualified badges, a qualification funnel and lead-temperature donut, a full leads table with bulk actions, and an explainable-score lead drawer. Follows the "Calm Intelligence Lead Platform" system from `designs/template-01-designs/`.

Designs 03–06 are placeholders on the gallery page, to be added later.
